# AGENTS.md: guide for AI agents working with TickerAtlas

## Using the data (read-only)
- Single lookups: `https://meridianalgo.github.io/TickerAtlas/api/stocks/{slug}.json` or `.../api/crypto/{slug}.json`. Slug rules are in `llms.txt`.
- Bulk: `data/All_Assets.csv` (every asset), `data/All_Stocks.csv` (full stock/ETF records), `data/Crypto.csv`.
- `ticker` is not unique across asset classes; use `id` (`stock:SOL` vs `crypto:SOL`).
- pandas: always `read_csv(..., keep_default_na=False, na_values=[""])`, or the ticker `NA` becomes NaN.
- This is reference data, not live prices. Cite the sources listed in `SOURCES.md`.

## Repository layout
| Path | Purpose |
| --- | --- |
| `src/build_stock_list.py` | Downloads NASDAQ Trader listings (`nasdaqlisted.txt` + `otherlisted.txt`), enriches via yfinance, writes `data/US_Stocks.*` / `data/Global_Stocks.*` |
| `src/build_global_universe.py` | Builds `inputs/global_tickers.txt` (Yahoo symbols) from local lists / optional EODHD |
| `src/combine_universes.py` | Merges US + global into `data/All_Stocks.{csv,sqlite}` and `data/All_Tickers.txt` |
| `src/build_crypto_list.py` | Downloads crypti/cryptocurrencies (pinned to the latest upstream commit) into `data/Crypto.*` |
| `src/build_asset_index.py` | Writes the unified `data/All_Assets.csv` |
| `src/build_site.py` | Generates the static website + JSON API into `_site/` (not committed) |
| `site/assets/` | Website CSS/JS used by `build_site.py` |
| `.github/workflows/update-stock-universe.yml` | Daily data refresh, commits `data/` |
| `.github/workflows/deploy-site.yml` | Builds and deploys `_site/` to GitHub Pages |

## Conventions
- Python 3.11, pandas. Keep build outputs deterministic so the daily job does not produce noisy commits.
- Don't hand-edit files in `data/`; they are regenerated by the scripts above.
- Don't commit `_site/`.
- Preview the site: `python src/build_site.py --out _site && python -m http.server 8000 --directory _site`. Add `--no-detail-pages` for a fast build.
- Lint: `ruff check . --select=E,W,F --ignore=E501`.
